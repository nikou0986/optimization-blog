Why Does Simplex Work?

The simplex method works because linear programming has a special geometric property.

Consider:

\[ \max z=5x_1+4x_2+3x_3 \]

subject to:

\[ \begin{aligned} 2x_1+3x_2+x_3 &\le5\\ 4x_1+x_2+2x_3 &\le11\\ 3x_1+4x_2+2x_3 &\le8\\ x_1,x_2,x_3&\ge0 \end{aligned} \]

The constraints define a feasible region.

Every point inside this region satisfies all constraints.

The fundamental theorem of linear programming states:

If an optimal solution exists, at least one optimal solution occurs at a vertex (corner point) of the feasible region.

Therefore, simplex does not need to search every possible point.

Instead, it searches through the vertices.

The question becomes:

How can we efficiently move from one vertex to another?

The answer comes from linear algebra.

Converting Inequalities into Equations

The simplex method works with equality constraints.

Therefore, we introduce slack variables.

A slack variable represents unused resources.

For example:

\[ 2x_1+3x_2+x_3\le5 \]

becomes:

\[ 2x_1+3x_2+x_3+s_1=5 \]

where:

\[ s_1\ge0 \]

The slack variable measures remaining capacity.

For example, if:

\[ 2x_1+3x_2+x_3=3 \]

then:

\[ s_1=2 \]

meaning two units of the resource remain unused.

Applying this to all constraints:

\[ \begin{aligned} 2x_1+3x_2+x_3+s_1&=5\\ 4x_1+x_2+2x_3+s_2&=11\\ 3x_1+4x_2+2x_3+s_3&=8 \end{aligned} \]

where:

\[ s_1,s_2,s_3\ge0 \]

To see the matrix structure clearly, write the slack coefficients explicitly:

\[ \begin{aligned} 2x_1+3x_2+x_3+1s_1+0s_2+0s_3&=5\\ 4x_1+x_2+2x_3+0s_1+1s_2+0s_3&=11\\ 3x_1+4x_2+2x_3+0s_1+0s_2+1s_3&=8 \end{aligned} \]

Matrix Representation

The system can be written as:

\[ Ax=b \]

where:

\[ A= \begin{bmatrix} 2&3&1&1&0&0\\ 4&1&2&0&1&0\\ 3&4&2&0&0&1 \end{bmatrix} \]

and:

\[ x= \begin{bmatrix} x_1\\ x_2\\ x_3\\ s_1\\ s_2\\ s_3 \end{bmatrix} \]

and:

\[ b= \begin{bmatrix} 5\\ 11\\ 8 \end{bmatrix} \]

The augmented matrix form is:

\[ \left[ \begin{array}{cccccc|c} 2&3&1&1&0&0&5\\ 4&1&2&0&1&0&11\\ 3&4&2&0&0&1&8 \end{array} \right] \]

The vertical line separates two parts:

  • The left side contains the coefficients of the variables.
  • The right side contains the available resources.

The left side answers:

How much does each variable contribute to each constraint?

The right side answers:

How much resource is available?

Where Does the Simplex Algorithm Start?

Before discussing the matrix basis, it is useful to understand the intuition.

The simplex method needs an initial feasible solution.

A natural starting point is:

\[ x_1=x_2=x_3=0 \]

This means we initially produce nothing.

Substituting into the constraints:

\[ \begin{aligned} s_1&=5\\ s_2&=11\\ s_3&=8 \end{aligned} \]

Therefore:

\[ (x_1,x_2,x_3,s_1,s_2,s_3) = (0,0,0,5,11,8) \]

All variables are nonnegative:

\[ x_i,s_i\ge0 \]

so this is a feasible solution.

The objective value is:

\[ z=5(0)+4(0)+3(0)=0 \]

Geometrically, this represents one vertex of the feasible region.

Which Variable Should Increase First?

The objective function is:

\[ z=5x_1+4x_2+3x_3 \]

The coefficients indicate how much the objective improves when increasing each variable.

  • Increasing \(x_1\) improves the objective by \(5\).

  • Increasing \(x_2\) improves the objective by \(4\).

  • Increasing \(x_3\) improves the objective by \(3\).

Therefore, simplex chooses:

\[ \boxed{x_1\text{ enters the solution}} \]

because it provides the largest improvement.

How Far Can We Increase \(x_1\)?

After choosing \(x_1\) to enter the solution, simplex needs to determine:

How far can we increase \(x_1\) before leaving the feasible region?

If we increase only \(x_1\), while keeping \(x_2=0\) and \(x_3=0\), the constraints become:

\[ 2x_1\le5 \]

\[ 4x_1\le11 \]

\[ 3x_1\le8 \]

Each constraint gives a different upper limit:

  • The first constraint gives \(x_1\le2.5\).
  • The second constraint gives \(x_1\le2.75\).
  • The third constraint gives \(x_1\le2.67\).

The smallest value determines how far we can move:

\[ x_1=2.5 \]

At this point:

\[ 2(2.5)=5 \]

meaning the first resource has been completely used.

The corresponding slack variable becomes:

\[ s_1=0 \]

The other resources still have remaining capacity:

\[ s_2=11-4(2.5)=1 \]

and:

\[ s_3=8-3(2.5)=0.5 \]

Therefore, only the first constraint becomes tight.

This process is called the minimum ratio test.

The minimum ratio test answers:

** Which constraint becomes active first, and therefore which variable must leave the basis?

From One Vertex to Another

At this moment, the simplex method has now moved from:

\[ (x_1,x_2,x_3)=(0,0,0) \]

to:

\[ (x_1,x_2,x_3)=(2.5,0,0) \]

The objective value improves from \(z=0\) to:

\[ z=5(2.5)+4(0)+3(0)=12.5 \]

The algorithm did not search every possible point between these two solutions.

Instead, it jumped directly from one vertex of the feasible region to another.

At the new vertex:

  • \(x_1\) has entered the solution.
  • \(s_1\) has become zero.

This exchange of variables is called a pivot.

NoteWhat Does “Entering” and “Leaving” Mean?

At the starting solution:

\[ (x_1,x_2,x_3,s_1,s_2,s_3)=(0,0,0,5,11,8) \]

the variables with positive values are \(s_1,s_2,s_3\).

These variables describe the current vertex.

Therefore, initially:

Basic variables:

\[ s_1,s_2,s_3 \]

Nonbasic variables:

\[ x_1,x_2,x_3 \]

After increasing \(x_1\):

\[ s_1=0 \]

so \(s_1\) can no longer define the current vertex.

The variables exchange roles:

Before:

\[ \text{Basic: }s_1,s_2,s_3 \]

After:

\[ \text{Basic: }x_1,s_2,s_3 \]

The variable exchange is:

\[ s_1\rightarrow x_1 \]

This is the first pivot.

Repeating the Process: The Second Move

After the first pivot, the simplex method has moved to:

\[ (x_1,x_2,x_3)=(2.5,0,0) \]

with:

\[ s_1=0,\qquad s_2=1,\qquad s_3=0.5 \]

The objective value is:

\[ z=12.5 \]

The simplex method now asks the same question again:

Can we improve the objective value further?

Which Variable Should Increase Next?

The objective function is still:

\[ z=5x_1+4x_2+3x_3 \]

At the current solution, \(x_1\) is already being used.

The remaining variables that can increase are:

\[ x_2,\qquad x_3 \]

Their contributions to the objective are:

  • Increasing \(x_2\) improves the objective by \(4\).
  • Increasing \(x_3\) improves the objective by \(3\).

Therefore, simplex chooses:

\[ \boxed{x_2\text{ enters the solution}} \]

because it provides the larger improvement.

How Far Can We Increase \(x_2\)?

Now we increase \(x_2\) while keeping:

\[ x_1=2.5,\qquad x_3=0 \]

Substitute into the constraints.

The first constraint becomes:

\[ 2(2.5)+3x_2\le5 \]

which gives:

\[ 5+3x_2\le5 \]

so:

\[ x_2\le0 \]

This means \(x_2\) cannot increase because the first constraint is already completely used.

The second constraint gives:

\[ 4(2.5)+x_2\le11 \]

so:

\[ 10+x_2\le11 \]

and:

\[ x_2\le1 \]

The third constraint gives:

\[ 3(2.5)+4x_2\le8 \]

so:

\[ 7.5+4x_2\le8 \]

and:

\[ x_2\le0.125 \]

The smallest allowable value is:

\[ x_2=0 \]

Therefore, \(x_2\) cannot enter the solution.

This tells us something important:

The current vertex is blocked in the \(x_2\) direction because the first constraint is already tight.

Try the Remaining Direction

Now test \(x_3\).

Keep:

\[ x_1=2.5,\qquad x_2=0 \]

The constraints become:

\[ 2(2.5)+x_3\le5 \]

\[ 4(2.5)+2x_3\le11 \]

\[ 3(2.5)+2x_3\le8 \]

The first constraint gives:

\[ 5+x_3\le5 \]

so:

\[ x_3\le0 \]

Again, \(x_3\) cannot increase.

Therefore, from this vertex, no variable can improve the objective value.

The simplex method stops.

The current solution is optimal:

\[ \boxed{ x_1=2.5,\quad x_2=0,\quad x_3=0 } \]

with:

\[ \boxed{ z=12.5 } \]

What Did Simplex Do?

The entire process was:

  1. Start at:

\[ (0,0,0) \]

  1. Choose \(x_1\) because it gives the largest objective improvement.

  2. Increase \(x_1\) until:

\[ s_1=0 \]

  1. Move to:

\[ (2.5,0,0) \]

  1. Check whether another variable can improve the objective.

  2. Since no variable can improve the solution, stop.

The simplex method therefore finds the optimal solution by repeatedly moving:

\[ \boxed{ \text{vertex}\rightarrow\text{vertex}\rightarrow\text{vertex} } \]

until reaching the best possible corner.

The Matrix View of Simplex: Changing the Basis

So far, we solved the simplex problem by looking at the constraints directly.

We identified:

  • which variable should enter,
  • which variable should leave,
  • and how far we can move.

This approach is intuitive and is often performed using a simplex tableau.

However, the simplex method can also be understood using linear algebra.

The key idea is:

Each vertex corresponds to a different choice of basis.

The simplex algorithm repeatedly changes the basis to move from one vertex to another.

What Is a Basis in Simplex?

Recall the matrix form:

\[ Ax=b \]

where:

\[ A= \begin{bmatrix} 2&3&1&1&0&0\\ 4&1&2&0&1&0\\ 3&4&2&0&0&1 \end{bmatrix} \]

The variables are:

\[ x= \begin{bmatrix} x_1\\ x_2\\ x_3\\ s_1\\ s_2\\ s_3 \end{bmatrix} \]

There are:

\[ 6 \]

variables but only:

\[ 3 \]

constraints.

Therefore, we cannot solve all variables simultaneously.

Instead, simplex selects:

\[ 3 \]

variables to be basic variables.

The remaining variables are called:

\[ \text{nonbasic variables} \]

and are set equal to zero.

At the initial solution:

\[ x_1=x_2=x_3=0 \]

The slack variables become:

\[ s_1=5,\quad s_2=11,\quad s_3=8 \]

Therefore, the initial basis is:

\[ B= \begin{bmatrix} 1&0&0\\ 0&1&0\\ 0&0&1 \end{bmatrix} \]

which corresponds to the columns:

\[ (s_1,s_2,s_3) \]

from the original matrix.

The solution is:

\[ Bx_B=b \]

Because:

\[ B=I \]

we immediately obtain:

\[ x_B=b \]

which gives:

\[ \begin{bmatrix} s_1\\ s_2\\ s_3 \end{bmatrix} = \begin{bmatrix} 5\\ 11\\ 8 \end{bmatrix} \]

The First Pivot as a Matrix Operation

Previously, we found:

\[ x_1 \]

should enter the basis.

The column corresponding to \(x_1\) is:

\[ a_1= \begin{bmatrix} 2\\ 4\\ 3 \end{bmatrix} \]

The current basis is:

\[ B= \begin{bmatrix} 1&0&0\\ 0&1&0\\ 0&0&1 \end{bmatrix} \]

The simplex method asks:

Can we replace one column of the basis with the new column \(a_1\)?

The answer comes from the ratio test.

We calculate:

\[ B^{-1}a_1=a_1 \]

because initially:

\[ B=I \]

Therefore:

\[ B^{-1}a_1= \begin{bmatrix} 2\\ 4\\ 3 \end{bmatrix} \]

The ratios are:

\[ \frac{5}{2}=2.5 \]

\[ \frac{11}{4}=2.75 \]

\[ \frac{8}{3}=2.67 \]

The smallest ratio is:

\[ 2.5 \]

Therefore, the first row limits the movement.

This means:

\[ s_1 \]

leaves the basis.

The new basis becomes:

\[ (x_1,s_2,s_3) \]

The new basis matrix is:

\[ B= \begin{bmatrix} 2&0&0\\ 4&1&0\\ 3&0&1 \end{bmatrix} \]

Solving the New Vertex Using Matrix Calculation

Once the basis changes, we solve:

\[ Bx_B=b \]

where:

\[ x_B= \begin{bmatrix} x_1\\ s_2\\ s_3 \end{bmatrix} \]

Therefore:

\[ \begin{bmatrix} 2&0&0\\ 4&1&0\\ 3&0&1 \end{bmatrix} \begin{bmatrix} x_1\\ s_2\\ s_3 \end{bmatrix} = \begin{bmatrix} 5\\ 11\\ 8 \end{bmatrix} \]

Solving:

First row:

\[ 2x_1=5 \]

so:

\[ x_1=2.5 \]

Second row:

\[ 4(2.5)+s_2=11 \]

so:

\[ s_2=1 \]

Third row:

\[ 3(2.5)+s_3=8 \]

so:

\[ s_3=0.5 \]

Therefore:

\[ x_B= \begin{bmatrix} 2.5\\ 1\\ 0.5 \end{bmatrix} \]

which gives the same vertex:

\[ (x_1,x_2,x_3) = (2.5,0,0) \]

The matrix calculation has reproduced the same simplex movement.

Reduced Cost: How Does Matrix Simplex Decide the Next Move?

The previous method looked at the objective coefficients directly.

The matrix method uses the idea of reduced cost.

The objective function is:

\[ z=c^Tx \]

where:

\[ c= \begin{bmatrix} 5\\4\\3\\0\\0\\0 \end{bmatrix} \]

For a given basis, we calculate:

\[ \bar{c}=c_N-c_B^TB^{-1}A_N \]

where:

  • \(c_N\) = objective coefficients of nonbasic variables
  • \(c_B\) = objective coefficients of basic variables
  • \(A_N\) = columns of nonbasic variables

The reduced cost tells us:

If this nonbasic variable enters the basis, will the objective improve?

If:

\[ \bar{c}_j>0 \]

for a maximization problem, increasing that variable improves the objective.

If:

\[ \bar{c}_j\le0 \]

for all variables, the current solution is optimal.

What If There Is No Optimal Solution?

The simplex method assumes that an optimal solution exists.

However, sometimes a linear programming problem does not have a finite optimal solution.

If this happens, there are two possible reasons:

  1. The problem is infeasible.
  2. The problem is unbounded.

These two cases represent two completely different failures.

Case 1: Infeasible Problem

A linear program is infeasible when there is no point that satisfies all constraints simultaneously.

In other words:

\[ \text{No feasible region exists} \]

The constraints are contradictory.

For example:

\[ x\ge5 \]

and:

\[ x\le3 \]

cannot both be true.

The feasible region is empty:

\[ \boxed{\text{Feasible region}=\emptyset} \]

Geometrically:

  • The constraints create boundaries.
  • However, these boundaries do not overlap.
  • Therefore, there is no vertex where simplex can start or move.

The simplex method fails because there is no feasible solution to improve.

Example of Infeasibility

Consider:

\[ \max z=x \]

subject to:

\[ x\le2 \]

and:

\[ x\ge5 \]

The first constraint says:

\[ x\in(-\infty,2] \]

while the second says:

\[ x\in[5,\infty) \]

There is no overlap:

\[ (-\infty,2]\cap[5,\infty)=\emptyset \]

Therefore:

\[ \boxed{\text{No feasible solution exists}} \]

How Does Simplex Detect Infeasibility?

The simplex method usually starts from a feasible solution.

For our previous example, the slack variables provided an obvious starting point:

\[ (s_1,s_2,s_3)=(5,11,8) \]

However, sometimes no such starting basis exists.

For example:

\[ x_1+x_2\ge5 \]

cannot create a feasible slack variable because adding a slack variable gives:

\[ x_1+x_2-s_1=5 \]

where:

\[ s_1\ge0 \]

The initial solution:

\[ x_1=x_2=0 \]

would give:

\[ -s_1=5 \]

or:

\[ s_1=-5 \]

which violates the nonnegativity requirement.

Therefore, simplex needs artificial variables and a Phase I procedure to search for feasibility.

If Phase I cannot find a feasible basis, the original problem is infeasible.

Case 2: Unbounded Problem

A linear program is unbounded when the objective value can continue increasing forever.

The feasible region exists, but it extends infinitely in a direction that improves the objective.

For a maximization problem:

\[ \max z=c^Tx \]

an unbounded problem means:

\[ z\rightarrow\infty \]

The simplex method keeps finding directions that improve the objective but never reaches a limiting vertex.

Example of an Unbounded Problem

Consider:

\[ \max z=x_1+x_2 \]

subject to:

\[ x_1-x_2\le2 \]

and:

\[ x_1,x_2\ge0 \]

The feasible region exists.

For example:

\[ (x_1,x_2)=(1,0) \]

satisfies the constraint.

However, we can increase both variables:

\[ x_1=t+2 \]

and:

\[ x_2=t \]

where:

\[ t\ge0 \]

The constraint becomes:

\[ (t+2)-t=2 \]

so it remains feasible.

The objective becomes:

\[ z=(t+2)+t \]

which simplifies to:

\[ z=2t+2 \]

As:

\[ t\rightarrow\infty \]

we get:

\[ z\rightarrow\infty \]

Therefore:

\[ \boxed{\text{The problem is unbounded}} \]

How Does Simplex Detect Unboundedness?

During a simplex iteration, suppose a variable has a positive reduced cost:

\[ \bar{c}_j>0 \]

meaning:

Increasing this variable improves the objective.

Normally, the ratio test determines how far we can increase this variable.

The ratio test is:

\[ \frac{b_i}{a_{ij}} \]

However, if every coefficient in the entering column satisfies:

\[ a_{ij}\le0 \]

then increasing the variable does not violate any constraint.

There is no leaving variable.

Therefore:

\[ \boxed{\text{The objective can increase forever}} \]

The simplex method stops and declares the problem unbounded.
